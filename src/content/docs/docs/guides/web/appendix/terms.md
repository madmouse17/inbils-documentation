---
title: "10.2 Terms"
description: "A glossary of the terms used in the Inbils web guide, from 2FA and isolir to SPK, ODN and maker-checker, with links to the sections."
---

| Term | Meaning |
| --- | --- |
| 2FA | Two-step authentication. A 6-digit code from an authenticator app is requested after the password ([section 1.4](/docs/guides/web/introduction/two-factor-authentication/)). |
| Akses dukungan (Support access) | A limited 30-minute session in which the platform operator signs in as a user to handle a complaint. It starts in read mode, is recorded in the company Log Audit (Audit log), and is marked by a banner at the top of the page. See the **Inbils Operator Panel Guide**. |
| Anak perusahaan (Subsidiary) | A company under one parent company, with data that stays separate. The platform operator creates it. The parent company admin requests it with **Minta anak perusahaan** (Request subsidiary) on the **Perusahaan** (Company) screen ([section 8.1](/docs/guides/web/administration/company/)). |
| Anggota (Member) | A user who comes from another company but is given membership in this company. In the **Pengguna** (Users) menu only their role in this company is managed ([section 8.5](/docs/guides/web/administration/users/)). |
| Aset jaringan (Network assets) | A network device that is tracked one by one, with a serial number, location and status (**Tersedia** (Available), **Terpasang** (Installed), **Perawatan** (Maintenance), **Rusak** (Damaged), or **Dipensiunkan** (Retired)) ([section 5.2](/docs/guides/web/network/network-assets/)). |
| Blokir internet (Block internet) | Manual network isolation of one subscription, with the button **Blokir internet** on the subscription or **Blokir** (Block) in **Tunggakan** (Arrears). A block is not a status, and payment does not remove it. **Buka blokir** (Unblock) removes it ([section 4.1](/docs/guides/web/customers-and-services/customers/) and [7.2](/docs/guides/web/finance-and-reports/arrears/)). |
| Break-glass | A direct stock adjustment by an admin without approval. The web screen does not offer the button ([section 6.5](/docs/guides/web/inventory/stock/)). |
| Buka kembali (Reopen) | A button on the ticket page that brings a ticket that is **Diselesaikan** (Resolved) or **Ditutup** (Closed) back into handling, with a required reason. It needs the `ticket.reopen` permission. The ticket target times are not recalculated ([section 9.2](/docs/guides/web/workflows/ticket-to-work-order/)). |
| Check-in | The location point that the technician app sends when starting a job. The ticket and work order (SPK) pages write its distance from the customer location in the **Check-in** row, and the technician's reason if they started farther than **Jarak check-in maksimal (meter)** (Maximum check-in distance (metres)) ([section 8.1](/docs/guides/web/administration/company/)). |
| Dibayar sebagian (Partially paid) | The status of an invoice that has received part of the payment and still has a remainder ([section 7.1](/docs/guides/web/finance-and-reports/invoices/)). An invoice that is already past its due date shows **Lewat jatuh tempo** (Overdue). |
| Dicadangkan (Reserved) | The stock quantity that is reserved by an approved item request ([section 6.5](/docs/guides/web/inventory/stock/)). |
| Dikembalikan (Returned) | The status of a work order whose result the approver rejected in **Persetujuan** (Approvals), with a reason ([section 3.2](/docs/guides/web/operations/approvals/)). The same word does not mean "Ditolak" (Rejected): the text **Ditolak** is used for item requests and stock adjustments. On a payment attempt, **Dikembalikan** means the money has been returned to the customer outside Inbils ([section 7.1](/docs/guides/web/finance-and-reports/invoices/)). |
| Diperoleh oleh (Acquired by) | The employee who is credited with acquiring the customer. The figures are read by Sales KPIs ([section 4.1](/docs/guides/web/customers-and-services/customers/) and [7.10](/docs/guides/web/finance-and-reports/sales-kpis/)). |
| Diserahkan (Handed over) | The status of an item request whose items the requester has received through **Serah terima** (Handover). Physical stock decreases, and the quantity column is named **Jumlah Diserahkan** (Quantity handed over) ([section 6.1](/docs/guides/web/inventory/item-requests/) and [9.3](/docs/guides/web/workflows/item-request-to-stock-issue/)). |
| Drill-down | Opening the source data rows behind one report figure through the link **Lihat data** (View data) ([section 7.3](/docs/guides/web/finance-and-reports/reports/)). |
| Ganti paket (Change package) | A button on the card **Paket** (Package) in the subscription details that moves the subscription to the latest version of a package ([section 4.1](/docs/guides/web/customers-and-services/customers/)). |
| Hapus permanen (Delete permanently) | Deletes master data that has never been used by other data, and cannot be undone. Data that is already in use can only be deactivated ([section 1.5](/docs/guides/web/introduction/know-the-screen/)). |
| Head | A parent company: a company without a parent that has at least one active subsidiary. In **Metrik Konsolidasi** (Consolidated metrics) it is marked with the badge **Induk** (Parent) ([section 1.6](/docs/guides/web/introduction/switch-company/)). |
| Hitungan tenggat (Deadline clock) | An option on the SLA tier: **24 jam** (24 hours) counts every hour, **Jam layanan** (Service hours) counts only the company opening hours. Targets from Ticket categories always count 24 hours ([section 4.5](/docs/guides/web/customers-and-services/sla-tiers/)). |
| Isolir (internet blocked while the account is suspended) | A restriction of network access for a customer in arrears. It runs automatically or with the button **Isolir** on **Tunggakan**, and the subscription gets status **Ditangguhkan** (Suspended) ([section 5.3](/docs/guides/web/network/nas-routers/) and [7.2](/docs/guides/web/finance-and-reports/arrears/)). |
| Izin (Permissions) | The right to one action, for example `spk.approve`. A role is a set of permissions ([section 8.6](/docs/guides/web/administration/roles/) and [8.7](/docs/guides/web/administration/permissions/)). |
| Jam layanan (Service hours) | Two things with the same name. In the company profile it is free text for customers in the app. In **Pengaturan Perusahaan** (Company settings) it is the opening hours schedule per day (with **Tutup** (Closed) for days off) that calculates the deadlines of SLA tiers with the **Jam layanan** clock. Keep the two consistent ([section 8.1](/docs/guides/web/administration/company/)). |
| Jarak check-in maksimal (Maximum check-in distance) | A setting in **Pengaturan Perusahaan**: the farthest distance from the customer location from which a technician may start a job without writing a reason. The default is 500 metres ([section 8.1](/docs/guides/web/administration/company/)). |
| Jenis Dokumen (Document types) | A menu in the group **Administrasi** (Administration) for customer document types: name, code, validity period and a required marker. The files are uploaded in the tab **Dokumen** (Documents) on the customer page ([section 8.8](/docs/guides/web/administration/documents/)). |
| Kuitansi (Receipt) | The PDF proof of payment for one **Lunas** (Paid) invoice, with the button **Unduh kuitansi** (Download receipt) on the invoice page. Unlike the invoice PDF, it does not contain the payment bank account ([section 7.1](/docs/guides/web/finance-and-reports/invoices/)). |
| Langganan (Subscription) | The service of one package for one customer. Its status is **Menunggu** (Pending), **Aktif** (Active), **Ditangguhkan**, or **Berhenti** (Terminated) ([section 4.1](/docs/guides/web/customers-and-services/customers/)). |
| Maker-checker | Separation of duties: the person who creates or submits must not decide its approval ([section 10.1](/docs/guides/web/appendix/roles-and-permissions-summary/)). |
| MRC | Monthly Recurring Charge, the subscription price per month. On a package it is named **Harga bulanan** (Monthly price), and on a subscription **Biaya bulanan** (Monthly fee) ([section 4.2](/docs/guides/web/customers-and-services/service-packages/)). |
| NAS | A router that forwards customer authentication to RADIUS ([section 5.3](/docs/guides/web/network/nas-routers/)). |
| Nonaktifkan (Deactivate) | Hides master data from new choices without changing its history. It is the only option for data that is already in use; **Hapus permanen** is only for data that has never been used ([section 1.5](/docs/guides/web/introduction/know-the-screen/)). |
| NPWP | Taxpayer identification number (nomor pokok wajib pajak), filled in the field **NPWP** of the customer ([section 4.1](/docs/guides/web/customers-and-services/customers/)). |
| ODN | Optical fibre network register: PON ports on the OLT, splitters on the ODC and ODP, and the drop port of each subscription. The OLT, ODC and ODP are registered as network assets ([section 5.5](/docs/guides/web/network/odn/)). |
| Operator platform (Platform operator) | A person in the Inbils team who uses the `/platform` panel: creates and suspends companies, maintains role templates, repairs company roles on request, and grants support access. Not a company user. See the **Inbils Operator Panel Guide**. |
| OTC | One-Time Charge, a one-off fee such as the installation fee. On a package it is named **Harga pemasangan** (Installation price), and on a subscription **Biaya pemasangan** (Installation fee) ([section 4.2](/docs/guides/web/customers-and-services/service-packages/)). |
| Panel perangkat (Device panel) | A drawing of a router, switch, OLT, ONU/ONT, ODC, ODP or rack like its real face, with ports coloured by status. The port sheet inside records labels, connections between devices, and the customer on each port ([section 5.6](/docs/guides/web/network/device-panel/)). |
| Penangan lain (Other handlers) | A row in the per-technician table of **Kepatuhan SLA** (SLA compliance) that groups ticket handlers outside your scope, so that the number of rows stays equal to the completed tickets ([section 7.6](/docs/guides/web/finance-and-reports/sla-compliance/)). |
| Penilaian pelanggan (Customer rating) | A rating from 1 to 5 that the customer gives for their ticket in the customer app, shown on the ticket page. The field with the same name in Evaluations ([section 3.5](/docs/guides/web/operations/evaluations/)) is filled from that rating if there is one. |
| Periode (Period) | The date range that a report calculates ([section 7.3](/docs/guides/web/finance-and-reports/reports/)). |
| Petugas tiket (Ticket handler) | The person assigned to handle a ticket ([section 3.4](/docs/guides/web/operations/tickets/)). |
| POP pelayan (Serving POP) | The POP location that serves a subscription ([section 4.1](/docs/guides/web/customers-and-services/customers/) and [5.5](/docs/guides/web/network/odn/)). |
| Port drop (Drop port) | The ODP output port that one subscription uses ([section 5.5](/docs/guides/web/network/odn/)). |
| PPN | Value added tax (pajak pertambahan nilai) on invoice items, at the company rate ([section 7.1](/docs/guides/web/finance-and-reports/invoices/)). |
| PPPoE, Hotspot | Two service types for a customer's network account ([section 4.1](/docs/guides/web/customers-and-services/customers/)). |
| Prefiks (Prefix) | An IP address block in CIDR notation that is recorded in IP addresses (**Alamat IP**) ([section 5.4](/docs/guides/web/network/ip-addresses/)). |
| Pulihkan (Restore) | Returns deleted data to the list with its original status, through the **Status** filter **Dihapus** (Deleted) ([section 1.5](/docs/guides/web/introduction/know-the-screen/)). |
| RADIUS | A network access authentication server. Inbils fills it with the customer's account and speed groups ([section 4.4](/docs/guides/web/customers-and-services/speed-profiles/) and [5.3](/docs/guides/web/network/nas-routers/)). |
| Respons pertama (First response) | The time when the handler first starts the ticket or replies to the customer ([section 3.4](/docs/guides/web/operations/tickets/)). |
| SLA | Service Level Agreement, the service time limit. The SLA tier is chosen on the package ([section 4.5](/docs/guides/web/customers-and-services/sla-tiers/)). The response and resolution targets of a ticket are taken from the SLA tier of its subscription package, or from the Ticket categories if there is no active tier ([section 3.4](/docs/guides/web/operations/tickets/)). The **Hitungan tenggat** of that tier decides whether hours outside opening hours are counted. |
| SPK | Surat Perintah Kerja, a field work order for technicians ([section 3.3](/docs/guides/web/operations/work-orders/)). |
| Splitter | A divider that turns one upstream port into several output ports, with a ratio of 1:2 to 1:64 ([section 5.5](/docs/guides/web/network/odn/)). |
| Templat peran (Role template) | A starting role that is copied into every new company when it is created. After copying, the role belongs to the company and does not change when the template is changed ([section 8.6](/docs/guides/web/administration/roles/)). |
| Tersedia (Available) | The stock quantity that can be used, which is **Jumlah** (Quantity) minus **Dicadangkan** ([section 6.5](/docs/guides/web/inventory/stock/)). |
| Tugaskan ke saya (Assign to me) | A button on the page of an **Terbuka** (Open) ticket that has no handler yet. A holder of `ticket.assign` who may handle tickets assigns it to themselves, unless the company forbids self-assignment ([section 9.2](/docs/guides/web/workflows/ticket-to-work-order/)). |
| Tugaskan sekarang (Assign now) | A block in the form **Buat Pelanggan** (Create customer) (tab **Langganan & SPK** (Subscription & work order)) to select the technician and the **Tanggal kunjungan** (Visit date) of the installation work order from registration, for holders of `spk.assign` ([section 9.1](/docs/guides/web/workflows/new-customer-to-payment/)). |
| Tunggakan (Arrears) | A menu that groups unpaid invoices per customer by age since the due date ([section 7.2](/docs/guides/web/finance-and-reports/arrears/)). |
| Undangan (Invitation) | An email with the button **Atur kata sandi** (Set password) for a new staff account, sent with **Kirim undangan** (Send invitation) in the form **Buat Pengguna** (Create user). The admin does not type a password for a staff account. **Kirim ulang undangan** (Resend invitation) on the user page sends a new link for an active account that has never signed in ([section 8.5](/docs/guides/web/administration/users/)). |
| Versi paket (Package version) | A record of the price, profiles, SLA tier and category of a package at a point in time. A subscription stays on the version it was sold with until it is moved with **Ganti paket** ([section 4.1](/docs/guides/web/customers-and-services/customers/) and [4.2](/docs/guides/web/customers-and-services/service-packages/)). |
| VLAN | A virtual network number that is recorded in IP addresses and linked to a prefix ([section 5.4](/docs/guides/web/network/ip-addresses/)). |
