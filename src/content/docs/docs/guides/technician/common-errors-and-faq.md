## Frequent messages


| Message | Cause and action |
| --- | --- |
| Tidak ada koneksi internet. Periksa sinyal, lalu coba lagi. (No internet connection. Check the signal, then try again.) | The phone is offline. Move to a place with signal, then tap **Coba lagi** (Try again). |
| Anda sedang offline. Data yang tampil mungkin belum terbaru. (You are offline. The data shown may not be the latest.) | The app shows the last copy. Pull the screen down after the signal recovers. |
| Butuh koneksi internet (An internet connection is needed) | That action cannot be saved for later: showing the PPPoE password, adding or deleting material, attachments, deleting a photo that has already been sent, cancelling an item request, the test notification. Start, I'm on my way, send for review, comments, complete ticket, declarations and item requests wait to send and do not show this message. |
| Anda sedang luring. Aksi disimpan dan dikirim otomatis saat online. (You are offline. Actions are saved and sent automatically when online.) | A banner on the work order (SPK), ticket and material return screens when the signal is lost. Your action is saved and sent by itself. Tap **Coba lagi** in the banner after the signal recovers. |
| N aksi gagal dikirim (N actions failed to send) | The server rejected a saved action, or an action may not have been sent. Tap **Lihat aksi** (View actions), then **Coba lagi** or **Buang** (Discard). |
| Belum pasti terkirim. Aksi ini mungkin sudah sampai, dan mengirim ulang tidak membuatnya ganda. (Not certain to have been sent. This action may have arrived, and sending again does not make it a duplicate.) | The server's answer did not reach the phone for about 30 minutes. Check the status on screen, then tap **Coba lagi** (does not create a duplicate) or **Buang**. |
| Jauh dari lokasi pelanggan (Far from the customer's location) | You pressed **Mulai** (Start) further away than the office limit. Write the **Alasan** (Reason), then tap **Mulai**. |
| Sesi Anda berakhir. Silakan masuk lagi. (Your session has ended. Please sign in again.) | The session ran out (30 days), the password or two-step verification settings changed, or the device was signed out. Sign in again. |
| Akun Anda dinonaktifkan. Hubungi kantor Inbils. (Your account has been deactivated. Contact the Inbils office.) | The admin deactivated the account. |
| Akun ini tidak terdaftar sebagai teknisi. (This account is not registered as a technician.) | The account is not yet entitled to use the technician app. Contact the office. |
| Terlalu banyak percobaan. Coba lagi dalam N detik. (Too many attempts. Try again in N seconds.) | The attempt limit has been reached. Wait for the countdown. |
| Data sudah berubah. Kami memuat ulang. (The data has changed. We are reloading.) | Someone else changed the data. Check the new screen, then repeat. |
| Permintaan sebelumnya masih diproses. Coba lagi sebentar lagi. (The previous request is still being processed. Try again shortly.) | The same action is still running. Wait a few seconds. |
| Server sedang bermasalah. Coba lagi beberapa saat lagi. (The server is having problems. Try again in a little while.) | A fault on the server side. Try again later. |


## FAQ


**What happens if the signal is lost at the site?**
The job list, work order and ticket details, notifications and item requests can still be read from the last copy. Work order photo evidence can still be taken and goes into the upload queue; photos are sent automatically when the signal returns, or tap **Kirim sekarang** (Send now). I'm on my way, Start, send for review, complete ticket, comments, material declarations and item requests are saved on the phone with the **Menunggu kirim** (Waiting to send) mark and then sent by themselves. Showing the PPPoE password, adding material, ticket attachments and deleting a photo that has already been sent need internet.

**My photo evidence has not been sent. What should I do?**
Open the **N foto belum terkirim** (N photos not sent yet) banner to see the queue. Tap **Kirim sekarang**. For a **Gagal** (Failed) photo, tap **Coba lagi** or delete it and take it again. Do not sign out before the queue is empty, because signing out deletes photos and actions that have not been sent.

**Why is the send-for-review button inactive?**
Read the red text below it. The cause is: there is no photo evidence yet, photos are still in the queue, or a material declaration has not been sent. Without internet the button can still be tapped; the action waits to send.

**My action says "Gagal dikirim" (Failed to send). What should I do?**
Read the reason under the action name. Tap **Coba lagi** if the problem is resolved (for example signal or distance), or **Buang** if the action is no longer needed. A rejected action holds back other actions on the same work order or ticket. If it reads "Belum pasti terkirim" (Not certain to have been sent), the action may have arrived: check its status on screen, then **Coba lagi** is safe because the server does not record it twice.

**Why does the app ask for a reason when I start?**
You are further from the customer's location than the limit set by the office (default 500 m). Write the reason, for example "Jalan ditutup, saya parkir di ujung gang" (The road is closed, I parked at the end of the alley), then tap **Mulai**. The office reads it on the work order or ticket.

**I forgot my password.**
Tap **Lupa kata sandi?** (Forgot password?) on the **Masuk** (Sign in) screen, enter your email, and open the link sent to your email. The new password is typed on the web page that the link opens.

**I lost the phone with this app.**
Sign in from another phone, open **Akun > Perangkat** (Account > Devices), and sign out the lost phone. Or change your password: all devices are signed out at once.

**My authenticator phone is lost.**
Use a recovery code on the **Verifikasi dua langkah** (Two-step verification) screen. If the recovery codes are also lost, ask the Inbils admin to reset the two-step verification of your account.

**Can I use the app on two phones?**
Yes. Each phone has its own session and appears in **Akun > Perangkat**.

**What size and type of photo are accepted?**
The server accepts JPG and PNG up to 10 MB. The app already shrinks photos to JPEG with a longest side of 1920 pixels before sending, so size is rarely a problem. Ticket attachments also accept PDF on the server side, but the app sends photos.

**Where do I set up two-step verification?**
On the Inbils website, on the profile page. The app only asks for it when you sign in.

**What cannot be done in the app.**
Changing the email, creating an account, setting up two-step verification, and resetting the password through the email link are done on the web or by the Inbils office.
