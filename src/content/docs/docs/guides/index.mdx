Four guides cover the whole product, one per kind of user. Each follows the screens in the order you meet them, and every page starts with the purpose of the screen and the roles that can use it. Screenshots show the real interface, which is in Indonesian: menu names, buttons and messages stay in Indonesian, with an English gloss the first time they appear on a page.
