Inbils adalah aplikasi manajemen ISP multi-tenant: pelanggan dan langganan, RADIUS dan MikroTik, SPK untuk teknisi, inventaris, billing dengan Midtrans, serta tiket dengan SLA, lengkap dengan dua aplikasi Android. Halaman-halaman ini mendokumentasikan aplikasi web, panel operator, dan kedua aplikasi, serta menjelaskan cara sistem dibangun dan dijalankan. Tersedia dalam bahasa Inggris dan Indonesia: ganti bahasa di header.
